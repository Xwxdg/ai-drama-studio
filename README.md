# AI Drama Studio｜AI 漫剧智能制作系统 V1.0

基于 React + TypeScript + Vite、Tailwind CSS 与 Lucide 的中文制作工作台。第一阶段使用本地规则和可编辑模板，不调用付费 API，不生成真实视频。

## 安装、启动与构建

要求 Node.js 22 或更新版本、npm。当前 Codex 环境使用 Node.js 24，并已安装依赖。

```bash
cd /workspace/ai-drama-studio
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

普通本地电脑可省略 `--cache /workspace/.npm-cache`，在仓库目录执行命令即可。开发服务器绑定 `0.0.0.0`，默认端口 5173。

```bash
npm run build
npm run preview -- --port 4173
npm test
npm run test:e2e
```

`npm run build` 执行 TypeScript 检查及生产构建，产物位于 `dist/`。`npm test` 验证解析、资产一致性、时间轴、两套模板、JSON 与 CSV；`npm run test:e2e` 使用真实 Chromium 验证制作闭环与异常提示，自动启动 Vite。当前环境使用 `/usr/bin/chromium`；其他环境可以设置 `CHROMIUM_PATH` 为已安装的 Chromium/Chrome 路径。浏览器测试不依赖 API Key。

在 Codex 中预览：运行开发命令后，如果当前客户端提供端口预览入口，选择 5173。客户端没有端口预览入口时，可把仓库克隆到本地并运行相同命令，然后在本地浏览器访问 Vite 打印的地址。云环境设置页面本身不提供 localhost 网页预览链接。

## 使用流程

1. 首次打开提供「雨夜来信」示例：2 个场次、2 名角色、12 个镜头。示例资产描述为人工演示数据。
2. 创建项目或切换项目，在「剧本管理」粘贴文本、修改、导入 UTF-8 TXT、保存草稿。
3. 「规则解析剧本」识别集数、场次标题、日夜/内外景、对白人物和常见道具；原始剧本完整保留。场次文本、事件、情绪、人物等可以手动修正。
4. 在三类资产库补全固定描述；支持新增、编辑、删除。角色包括年龄、体型、面部、发型、服装、声音；场景包括布局、材质、光源和环境锚点；道具包括外观、材质和使用信息。
5. 生成规则分镜初稿，点击表格行在右侧编辑全部字段、关联资产、填写站位。支持增删、复制、上下移动。已确认镜头不会被重新生成覆盖；重新生成会保留它们并置于前方，其余镜头需确认后替换。重排不会改写镜头内容。
6. 「时间轴编辑」根据顺序和时长自动计算连续起止秒数，支持目标时长、预设和重排。起止时间为派生值，通过前序镜头时长调整，避免人工填写造成缺口。允许选择任意多个镜头规划片段。
7. 「视频提示词生成」选择独立的 Seedance 2.5 或 Wan 3.0 模板、画幅、风格、画质目标，勾选单个或多个镜头，也可按开始/结束镜号指定连续片段（界面显示原时间轴起止秒数）。所选镜头始终按原顺序合并；不选时使用全部。支持编辑模板、编辑输出、复制、TXT 导出及按完整镜头分段。单镜头超过分段上限时不会擅自切割，应手动拆分。
8. 「文件导出」提供完整 CSV、TXT 和项目 JSON。CSV 为 UTF-8 BOM、标准引号转义，可供 Excel 打开。JSON 恢复会校验结构并创建独立副本，不覆盖现有项目。

## 真实能力与限制

- **已实现且可操作**：项目创建/更名/保存/打开/删除、浏览器自动保存、TXT 导入、场次编辑、三类资产 CRUD、完整字段分镜编辑与资产关联、连续时间轴、独立模板、镜头选择合并、复制与导出、JSON 备份恢复、中文错误提示。
- **规则处理**：场次标题和对白模式匹配、常见道具关键词识别、每行一个镜头，摄影参数使用可解释的默认值。没有语义模型，复杂剧本格式、隐含人物、动作含义与情绪须人工补充。重新解析不会覆盖已有分镜。
- **一致性提醒**：检查缺失资产、同场次场景变化、服装描述变化、道具引用减少、站位与机位变化、非法时长及目标时长差异。提醒是人工复核线索，不能证明人物、动作或视线连续，未进行 AI 视觉验证。
- **模型模板**：Seedance 以视频规划、资产约束、时间序列组织；Wan 以主体世界、构图、镜头调度与动作衔接组织。独立文件与项目级可编辑配置。模型名称、版本、接口、支持时长和分辨率尚未核实；并非已完成真实模型适配。
- **规划参数**：30 秒时间轴、16:9/9:16、1080P/4K/8K 为制作与提示词目标，不保证模型输出能力。
- **尚未实现**：真实 AI 推理、视频生成、模型 API 配置与调用、云同步、DOCX/PDF 导入、DOCX/PDF/XLSX 导出。

## 本地数据与备份

项目保存在当前来源的 `localStorage`（键 `ai-drama-studio-v1`）。所有项目会自动保存，刷新不会丢失已成功保存的数据；刷新后默认打开列表中的首个项目，其他项目可通过下拉框重新打开。修改提示词后会保留人工结果；资产或镜头修改后可点击「重新生成提示词」更新，避免覆盖人工精修。模型切换会展示对应模板。

浏览器隐私模式、配额不足或禁用存储可能导致保存失败，界面会用中文提示。若已有存储无法解析，打开示例但不自动覆盖原存储；用户可导出备份后明确保存或恢复。JSON 是跨浏览器与设备恢复方式。项目包含完整原始剧本、资产、镜头、模型配置、独立模板与当前提示词。删除项目、镜头和资产均要求确认。资产删除不会静默改写镜头，连贯性检查会提醒残留引用。

不要把 API Key 放入源代码、项目 JSON 或浏览器存储。后续模型调用应增加服务端代理并安全管理凭据。

## 代码结构

- `src/App.tsx`：工作台导航、页面、属性编辑与交互。
- `src/domain.ts`：项目类型、规则解析、分镜、时间轴、校验和 CSV。
- `src/models/seedance.ts`、`src/models/wan.ts`：独立提示词模板。
- `src/prompts.ts`：资产描述合并、时间轴渲染、片段拆分。
- `src/style.css`：深色桌面工作台与窄屏适配。
- `src/domain.test.ts`、`tests/workflow.spec.ts`：逻辑和真实浏览器测试。
